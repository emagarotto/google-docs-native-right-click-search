# Privacy Policy for Search Google in Docs

**Last Updated:** November 18, 2026

## Overview
**Search Google in Docs** is a Chrome browser extension designed with a single purpose: allowing users to search Google for highlighted text directly from the Google Docs right-click context menu.

## Data Collection & Usage
* **No Data Collection:** This extension does **not** collect, store, log, or transmit any personal information, browsing history, document contents, or clipboard data to any external server or third party.
* **Local Processing Only:** When you click **"Search Google for selection"** in the Google Docs context menu, the extension triggers a local copy of your highlighted text and reads that text from your device's clipboard solely to construct a Google Search URL (`https://www.google.com/search?q=...`) in a new browser tab.
* **No Analytics or Tracking:** This extension does not use cookies, telemetry, analytics trackers, or advertisements.

## Permissions Explanation
* **`clipboardRead`:** Used strictly to read the selected text copied when you click the search menu option so it can be passed to your Google search tab.
* **`https://docs.google.com/document/*`:** Required to inject the search option into the Google Docs right-click context menu.

## Contact
If you have any questions about this privacy policy or how the extension operates, please contact the developer through the Chrome Web Store support tab.
